# 기준 버전 조사 기록 (2026-08-04)

## 확정 사항

- Ubuntu 26.04 LTS의 코드명은 Resolute Raccoon이다.
- 출시일은 2026-04-23이며 표준 지원은 2031년까지다.
- Ubuntu 26.04 기본 저장소의 PostgreSQL 메타 패키지는 PostgreSQL 18을 설치한다.
- amd64용 `postgresql-18` 패키지는 확인 시점에 `18.4-0ubuntu0.26.04.1`이다.
- 교재의 기본 설치 경로는 Ubuntu 기본 저장소로 한정한다. PostgreSQL 공식 Apt 저장소(PGDG)는 버전 선택이 필요한 독자를 위해 후속 장이나 보충 자료에서 비교한다.
