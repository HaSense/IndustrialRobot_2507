# PostgreSQL 학생 데이터 Streamlit 화면에 출력하기

이 문서는 WSL Ubuntu 24.04 환경에서 PostgreSQL의 `student` 테이블 데이터를 조회하여 Streamlit 화면에 출력하는 과정을 설명합니다.

전체 데이터 흐름은 다음과 같습니다.

```text
PostgreSQL
    ↓
Psycopg
    ↓
Pandas DataFrame
    ↓
Streamlit
    ↓
웹 브라우저
```

---

## 1. 사전 준비

이 문서는 다음 PostgreSQL 데이터베이스와 테이블이 이미 생성되어 있다고 가정합니다.

- 데이터베이스: `school`
- 테이블: `student`

테이블 구조 예시는 다음과 같습니다.

```sql
CREATE TABLE student
(
    id SERIAL PRIMARY KEY,
    name VARCHAR(30),
    age INT
);
```

샘플 데이터는 다음과 같이 등록할 수 있습니다.

```sql
INSERT INTO student(name, age)
VALUES
('홍길동', 20),
('김철수', 22),
('이영희', 19),
('박민수', 25);
```

## 5. Streamlit 전용 PostgreSQL 사용자 생성

Streamlit 프로그램에서 PostgreSQL에 접속할 때 `postgres` 관리자 계정을 직접 사용하는 것은 권장하지 않습니다.

애플리케이션에서 사용할 일반 사용자 계정을 별도로 생성합니다.

### 5.1 PostgreSQL 관리자 계정으로 접속

```bash
sudo -u postgres psql
```

다음과 같이 PostgreSQL 프롬프트가 표시되면 관리자 계정으로 접속된 것입니다.

```text
postgres=#
```

### 5.2 애플리케이션 사용자 생성

```sql
CREATE USER student_app
WITH PASSWORD 'student1234';
```

> 예제의 비밀번호는 교육용입니다. 실제 운영 환경에서는 충분히 복잡한 비밀번호를 사용해야 합니다.

## 6. 데이터베이스와 테이블 권한 부여

### 중요한 권한 원칙

`student_app`과 같은 일반 PostgreSQL 사용자 계정은 자신에게 필요한 권한을 스스로 부여할 수 없습니다.

다음 권한 부여 명령은 일반 사용자 계정이 아니라 아래 계정 중 하나로 실행해야 합니다.

- PostgreSQL 관리자 계정
- 해당 데이터베이스나 테이블의 소유자 계정
- 권한을 다른 사용자에게 부여할 수 있는 권한을 가진 계정

이 예제에서는 PostgreSQL 기본 관리자 계정인 `postgres`로 접속한 상태에서 권한을 부여합니다.

### 6.1 데이터베이스 접속 권한 부여

```sql
GRANT CONNECT ON DATABASE school TO student_app;
```

### 6.2 school 데이터베이스로 이동

```sql
\c school
```

### 6.3 public 스키마 사용 권한 부여

```sql
GRANT USAGE ON SCHEMA public TO student_app;
```

### 6.4 student 테이블 조회 권한 부여

```sql
GRANT SELECT ON TABLE student TO student_app;
```

현재 예제는 조회 기능만 구현하므로 `SELECT` 권한만 부여합니다.

나중에 Streamlit 화면에서 학생 등록, 수정, 삭제 기능까지 구현하려면 관리자 또는 테이블 소유자 계정으로 다음 권한을 추가할 수 있습니다.

```sql
GRANT INSERT, UPDATE, DELETE
ON TABLE student
TO student_app;
```

`SERIAL` 컬럼을 사용하는 테이블에 일반 사용자가 데이터를 추가할 때는 시퀀스 권한도 필요할 수 있습니다.

```sql
GRANT USAGE, SELECT
ON SEQUENCE student_id_seq
TO student_app;
```

권한 부여가 끝나면 PostgreSQL 콘솔을 종료합니다.

```sql
\q
```

## 7. 일반 사용자 계정으로 접속 테스트

Streamlit 코드를 작성하기 전에 `student_app` 계정으로 접속 가능한지 확인합니다.


```text

```

```sql

```

정상적으로 조회되면 접속과 권한 설정이 완료된 것입니다.

```sql
\q
```

`-h localhost` 옵션을 사용하면 PostgreSQL 서버에 TCP 방식으로 접속하며 비밀번호 인증을 사용하게 됩니다.

## 10. Streamlit 프로그램 작성

`app.py` 파일을 생성합니다.

```bash
nano app.py
```

다음 코드를 작성합니다.

```python
import os

import pandas as pd
import psycopg
import streamlit as st
from dotenv import load_dotenv


# .env 파일의 환경변수를 읽습니다.
load_dotenv()


def get_connection():
    """PostgreSQL 연결 객체를 반환합니다."""
    return psycopg.connect(
        host=os.getenv("DB_HOST"),
        port=os.getenv("DB_PORT"),
        dbname=os.getenv("DB_NAME"),
        user=os.getenv("DB_USER"),
        password=os.getenv("DB_PASSWORD"),
    )


def fetch_students() -> pd.DataFrame:
    """student 테이블의 전체 데이터를 조회합니다."""
    sql = """
        SELECT
            id,
            name,
            age
        FROM student
        ORDER BY id
    """

    with get_connection() as connection:
        with connection.cursor() as cursor:
            cursor.execute(sql)

            rows = cursor.fetchall()
            columns = [column.name for column in cursor.description]

    return pd.DataFrame(rows, columns=columns)


st.set_page_config(
    page_title="학생 관리",
    page_icon="🎓",
    layout="wide",
)

st.title("🎓 학생 목록")
st.write("PostgreSQL의 `student` 테이블 데이터를 조회합니다.")

try:
    students = fetch_students()

    if students.empty:
        st.info("등록된 학생이 없습니다.")
    else:
        st.metric("전체 학생 수", len(students))

        st.dataframe(
            students,
            width="stretch",
            hide_index=True,
        )

except psycopg.Error as error:
    st.error("PostgreSQL 데이터베이스 연결 또는 조회 중 오류가 발생했습니다.")
    st.code(str(error))
```

## 15. 최소 나이 검색 기능 추가

다음과 같이 최소 나이를 입력받아 PostgreSQL에서 조건 검색할 수 있습니다.

```python
def fetch_students(minimum_age: int = 0) -> pd.DataFrame:
    sql = """
        SELECT
            id,
            name,
            age
        FROM student
        WHERE age >= %s
        ORDER BY id
    """

    with get_connection() as connection:
        with connection.cursor() as cursor:
            cursor.execute(sql, (minimum_age,))

            rows = cursor.fetchall()
            columns = [column.name for column in cursor.description]

    return pd.DataFrame(rows, columns=columns)
```

Streamlit 입력 컴포넌트를 추가합니다.

```python
minimum_age = st.number_input(
    "최소 나이",
    min_value=0,
    max_value=100,
    value=0,
    step=1,
)

students = fetch_students(minimum_age)
```

Psycopg에서는 SQL 값 자리에 `%s`를 사용하고, 실제 값은 두 번째 인자로 전달합니다.

```python
cursor.execute(sql, (minimum_age,))
```

다음처럼 사용자 입력을 문자열 조합으로 SQL에 직접 넣는 방식은 사용하지 않는 것이 좋습니다.

```python
# 권장하지 않는 방식
sql = f"SELECT * FROM student WHERE age >= {minimum_age}"
```

매개변수 바인딩을 사용하면 SQL Injection 위험을 줄이고 데이터 타입 처리도 더 안전하게 할 수 있습니다.

## 핵심 정리

- Streamlit 애플리케이션에서는 PostgreSQL 관리자 계정을 직접 사용하지 않습니다.
- 애플리케이션 전용 일반 사용자 계정을 생성합니다.
- `GRANT` 명령은 일반 사용자 계정이 아니라 관리자, 객체 소유자 또는 권한 부여 권한을 가진 계정으로 실행해야 합니다.
- 조회 전용 애플리케이션에는 필요한 최소 권한인 `CONNECT`, `USAGE`, `SELECT`만 부여합니다.
- 데이터베이스 비밀번호는 `.env` 파일로 분리하고 `.gitignore`에 등록합니다.
- PostgreSQL 조회 결과는 Pandas DataFrame으로 변환한 후 `st.dataframe()`으로 출력할 수 있습니다.
