## 명령 표기 규칙

- `YOUR-ID`: 자신의 GitHub 사용자명으로 변경
- `REPOSITORY`: 실제 저장소 이름으로 변경
- `ORIGINAL-OWNER`: 원본 저장소 소유자로 변경
- `student@example.com`: 자신의 이메일 또는 GitHub 비공개 이메일로 변경

명령 앞의 `$`는 입력하지 않으며, 토큰·비밀번호·SSH 개인키는 교재나 저장소에 기록하지 않는다.

## 기준 환경

- Windows 11 + WSL2
- Ubuntu
- Git
- GitHub.com
- GitHub CLI(`gh`)
- Visual Studio Code + WSL 확장

GitHub 화면과 패키지 버전은 변경될 수 있다. 인증과 설치에서 화면이 다르면 각 장에 연결된 공식 문서를 우선 확인한다.
