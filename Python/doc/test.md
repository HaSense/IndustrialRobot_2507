# 생산실적 등록

## 사용자 스토리

생산 작업자로서 생산수량과 불량수량을 등록하고 싶다.

## 인수 조건

- [ ] 품목을 선택할 수 있다.
- [ ] 생산수량을 입력할 수 있다.
- [ ] 불량수량은 생산수량을 초과할 수 없다.
- [ ] 저장된 결과가 생산실적 목록에 표시된다.
