# WSL 포트 포워딩 설정

Windows에서 WSL 내부 서비스(Apache, Streamlit)에 외부 PC가 접속할 수 있도록 포트 포워딩과 방화벽 규칙을 설정한다.

> 아래 명령어는 **관리자 권한으로 실행한 명령 프롬프트(CMD)** 에서 실행한다.
>
> WSL의 IP 주소(`172.27.44.251`)는 WSL을 재시작하면 변경될 수 있다.

## 1. 기존 Apache 포트 포워딩 규칙 삭제

```cmd
netsh interface portproxy delete v4tov4 ^
listenaddress=0.0.0.0 ^
listenport=80
```

## 2. Apache 포트 포워딩 규칙 추가

Windows의 `80`번 포트로 들어온 요청을 WSL의 `80`번 포트로 전달한다.

```cmd
netsh interface portproxy add v4tov4 ^
listenaddress=0.0.0.0 ^
listenport=80 ^
connectaddress=172.27.44.251 ^
connectport=80
```

## 3. Streamlit 포트 포워딩 규칙 추가

Windows의 `8501`번 포트로 들어온 요청을 WSL의 `8501`번 포트로 전달한다.

```cmd
netsh interface portproxy add v4tov4 ^
listenaddress=0.0.0.0 ^
listenport=8501 ^
connectaddress=172.27.44.251 ^
connectport=8501
```

## 4. Windows 방화벽 인바운드 규칙 추가

### Apache 80번 포트 허용

```cmd
netsh advfirewall firewall add rule ^
name="WSL Apache 80" ^
dir=in ^
action=allow ^
protocol=TCP ^
localport=80
```

### Streamlit 8501번 포트 허용

```cmd
netsh advfirewall firewall add rule ^
name="WSL Streamlit 8501" ^
dir=in ^
action=allow ^
protocol=TCP ^
localport=8501
```

## 5. 설정 확인

등록된 포트 포워딩 규칙을 확인한다.

```cmd
netsh interface portproxy show all
```

등록된 방화벽 규칙을 확인한다.

```cmd
netsh advfirewall firewall show rule name="WSL Apache 80"
netsh advfirewall firewall show rule name="WSL Streamlit 8501"
```

## 6. 접속 주소

다른 PC에서 Windows 호스트의 IP 주소를 이용해 접속한다.

- Apache: `http://Windows_IP`
- Streamlit: `http://Windows_IP:8501`

Windows 호스트의 IP 주소는 다음 명령어로 확인할 수 있다.

```cmd
ipconfig
```

## 참고: Streamlit 실행 예시

외부 접속을 허용하려면 Streamlit이 모든 네트워크 인터페이스에서 요청을 받도록 실행한다.

```bash
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```
