# Streamlit 로그인 샘플

SQLite DB 파일은 앱 실행 시 `./sql/sample.db`에 자동 생성됩니다.

## 실행

```bash
streamlit run app.py
```

기본 계정:

- 아이디: `admin`
- 비밀번호: `admin1234`

회원가입 탭에서 새 사용자를 추가할 수도 있습니다.

로그인 후 사이드바 메뉴에서 다음 페이지를 선택할 수 있습니다.

- 실습: 세션 카운터, 임시 메모, 세션 장바구니와 DB 저장 실습
- 세션 설명: `st.session_state`와 DB 저장의 차이 설명
- 단계별 예제: 세션 기초부터 장바구니 DB 저장까지 코드 예제
- 단계별 실습: demo 세션값으로 예제를 직접 테스트
- 제작 과정: 로그인, 세션, DB 저장 기능을 만드는 순서
- 개발 지침: 파일 분리 방향과 주의할 점
- DB/세션 비교: 현재 DB 저장값과 세션 저장값 비교

## Session State 예시

로그인 후 화면에서 다음 값을 `st.session_state`로 관리합니다.

- 로그인 시각: DB에 저장하지 않고 현재 세션에만 유지
- 화면 실행 횟수: Streamlit rerun이 일어날 때마다 자동 증가
- 수동 카운터: 카운터 버튼을 누를 때마다 직접 증가하고 초기화 가능
- 임시 메모: 새로고침이나 버튼 클릭 후에도 현재 세션 동안 유지
- 세션 장바구니: 상품을 담고 비우는 임시 목록
- 화면 표시 모드: 현재 세션에서만 유지되는 사용자 선택값

## DB와 세션 비교

로그인 후 화면에는 두 종류의 값이 나란히 표시됩니다.

- DB 저장값: 사용자 ID, 아이디, 표시 이름, 계정 생성 시각, DB에 저장된 장바구니 항목 수
- 세션 저장값: 로그인 시각, 화면 실행 횟수, 수동 카운터, 장바구니, 임시 메모, 화면 표시 모드

비밀번호 해시와 salt는 보안상 화면에 표시하지 않습니다.

## 세션 장바구니와 DB 저장 실습

로그인 후 `세션 장바구니와 DB 저장 실습` 영역에서 세션 상태와 DB 저장의 차이를 확인할 수 있습니다.

- 상품 담기: 노트북, 마우스, 키보드, 모니터를 세션 장바구니에만 추가
- 세션 장바구니 취소: DB에 저장하지 않고 현재 세션 장바구니만 비움
- DB에 저장: 현재 세션 장바구니를 `saved_cart_items` 테이블에 저장한 뒤 세션 장바구니를 비움
- `st.dataframe`: DB에 저장된 장바구니 항목을 pandas DataFrame으로 조회해서 표시
- 선택 항목 삭제: 선택한 DB 저장 항목을 SQLite에서 삭제

이 흐름은 `세션에만 있던 임시 데이터`가 사용자의 저장 동작 후 `DB에 남는 데이터`로 바뀌는 과정을 보여주기 위한 예시입니다.
